# 二进制悬浮窗 · BinFloater

一个常驻桌面的小悬浮窗：**复制 0/1 串就自动翻译成文字**，也能把输入的文字实时转成二进制。

> **这个项目全部由 AI 制作。**
> 代码、图标、打包配置、这份文档，全部由 AI 编写。人类只负责提需求和在真机上试用。
> 详见[关于作者](#关于作者)。

## 怎么启动（重要）

**双击本目录下的 `启动.bat`**，或直接双击：

```
dist\BinFloater\BinFloater.exe
```

免安装、免 Python 环境。

> ⚠️ 如果之前那一版 `dist\BinFloater.exe`（单文件版）弹过
> `Could not create temporary directory!`，请看下面的[关于单文件版报错](#关于单文件版报错)。
> 新版已改用文件夹模式，不会再出现这个问题。

## 三种启动方式

| 方式 | 入口 | 适用场景 |
| --- | --- | --- |
| ① 文件夹版（推荐） | `启动.bat` 或 `dist\BinFloater\BinFloater.exe` | 日常使用，启动最快最稳 |
| ② 源码运行 | `pythonw main.py`（需 Python 3.8+） | 想改代码，或用 `python main.py` 看报错 |
| ③ 命令行直转 | `BinFloater.exe --decode "01001000 01101001"` | 不进界面，只要结果 |

## 功能

### 1. 剪切板自动翻译（二进制 → 文字）

在任意程序里复制一段 0/1 串，悬浮窗会立刻显示译文：

| 你复制的内容 | 识别结果 |
| --- | --- |
| `01001000 01101001` | `Hi` |
| `0100100001101001` | `Hi` |
| `0b01001000_0b01101001` | `Hi` |
| `0100-1000 0110-1001` | `Hi` |
| `111001001011110110000000...` | 中文（UTF-8） |

支持的分隔风格：空格、换行、逗号、分号、下划线、短横线、`0b` 前缀，以及完全连写。
编码按 `UTF-8 → GBK → Big5 → Latin-1` 依次尝试，中文和 emoji 不会乱码。

复制普通文字时不会打扰你，只会在状态栏提示"按 Ctrl+B 可转二进制"。

### 2. 文字 → 二进制

在下方输入框里打字，二进制**实时**显示在下方：

- `Hello 世界` → `01001000 01100101 ...`（UTF-8 编码）
- 点「复制二进制」或按 **Enter** 一键复制
- 点「紧凑」可去掉空格，输出成 `0100100001101001` 连写形式
- 点「← 从剪切板」把剪切板里的文字拉进输入框

### 3. 顺手的小功能

- **自动回写**：识别到二进制后，自动把译文写回剪切板（默认关闭，点一下开启）
- **折叠**：点 ▲ 收成一条标题栏，折叠时标题栏直接显示译文，不挡视线
- **透明**：点 ◐ 在 100% / 92% / 80% / 65% 之间切换
- **置顶**：点 ◉ 切换窗口置顶（青色表示已置顶）
- 窗口位置、透明度、开关状态会自动记住
- 单实例运行：重复双击不会开第二个窗口，而是把已有窗口提到最前

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Enter`（输入框内） | 复制二进制 |
| `Ctrl+B` | 把剪切板文字转成二进制 |
| `Ctrl+Q` | 退出 |
| `Esc` | 折叠 / 展开 |
| 双击标题栏 | 折叠 / 展开 |
| 拖动标题栏或空白处 | 移动窗口 |

## 命令行用法

```bash
BinFloater.exe --decode "01001000 01101001"   # 输出 Hi
BinFloater.exe --encode "Hi"                  # 输出 01001000 01101001
```

## 关于单文件版报错

**报错内容**

```
Error
Could not create temporary directory!
```

**原因**

这是 PyInstaller **单文件版（onefile）** 的固有问题，不是程序逻辑的 bug。

单文件版每次启动时，都要先把自身 11 MB 的内容解包到
`%TEMP%\_MEIxxxxxx` 临时目录，再从那里加载 Python 运行库。
这一步会被安全软件拦截：

- **360安全卫士 / 火绒**的文件实时防护会拦截"可执行文件批量释放 DLL"的行为
- 部分环境 TEMP 变量被指向无效路径（比如从 Git Bash 继承 `TEMP=/tmp`）
- 临时目录权限不足或磁盘空间紧张

**已做的修复**

1. **改用文件夹版（onedir）** —— 依赖直接放在 `dist\BinFloater\_internal\`，
   启动时完全不解包，不需要任何临时目录，启动耗时从 2.5 秒降到 **0.5 秒**。
2. 新增 `启动.bat`，按"文件夹版 → 单文件版 → 源码"顺序自动挑可用的方式启动。
3. 删除单文件版的打包配置，避免以后再误打误撞出同样的问题。

## 目录结构

```
binfloater/
├── 启动.bat           一键启动（优先文件夹版）
├── main.py            入口：单实例检查 + 命令行直转
├── gui.py             悬浮窗界面（tkinter）
├── core.py            编解码逻辑（纯函数，可单独复用）
├── clipwin.py         Win32 剪切板读写与变化监听（ctypes）
├── build_onedir.spec  PyInstaller 打包配置（文件夹模式）
├── make_icon.py       生成图标
└── dist/
    └── BinFloater/    文件夹版（双击 BinFloater.exe）
```

## 自己打包

```bash
pip install pyinstaller pillow
python make_icon.py
python -m PyInstaller build_onedir.spec --noconfirm --clean
```

产物在 `dist/BinFloater/`，整个文件夹拷走就能用（约 26 MB）。

## 说明

- 只识别 **Unicode 文本**格式的剪切板内容；图片、文件、HTML 等格式会被忽略。
- 二进制判定阈值：去掉分隔符后至少 16 位，且只由 0/1 组成。像 `2024` 这类纯数字不会被误判。
- 位数不是 8 的倍数时，末尾会自动补 0 并在状态栏提示。
- 配置保存在 `%APPDATA%\BinFloater\config.json`。
- 复制到别处使用时，请**拷贝整个 `BinFloater` 文件夹**，不要只拷 exe。
