# 二进制悬浮窗 · BinFloater

一个常驻桌面的小悬浮窗：**复制 0/1 串就自动翻译成文字**，也能把输入的文字实时转成二进制。

> **这个项目全部由 AI 制作。**
> 代码、图标、打包配置、这份文档，全部由 AI 编写。人类只负责提需求和在真机上试用。
> 详见[关于作者](#关于作者)。

![界面预览](screenshot.png)

## 怎么启动（重要）

**双击本目录下的 `启动.bat`**，或直接双击：

```
dist\BinFloater\BinFloater.exe
```

免安装、免 Python 环境。

> ⚠️ 如果之前那一版 `dist\BinFloater.exe`（单文件版）弹过
> `Could not create temporary directory!`，请看下面的[关于单文件版报错](#关于单文件版报错)。
> 新版已改用文件夹模式，不会再出现这个问题。

## 三种启动方式

| 方式 | 入口 | 适用场景 |
| --- | --- | --- |
| ① 文件夹版（推荐） | `启动.bat` 或 `dist\BinFloater\BinFloater.exe` | 日常使用，启动最快最稳 |
| ② 源码运行 | `pythonw main.py`（需 Python 3.8+） | 想改代码，或用 `python main.py` 看报错 |
| ③ 命令行直转 | `BinFloater.exe --decode "01001000 01101001"` | 不进界面，只要结果 |

## 功能

### 1. 剪切板自动翻译（二进制 → 文字）

在任意程序里复制一段 0/1 串，悬浮窗会立刻显示译文：

| 你复制的内容 | 识别结果 |
| --- | --- |
| `01001000 01101001` | `Hi` |
| `0100100001101001` | `Hi` |
| `0b01001000_0b01101001` | `Hi` |
| `0100-1000 0110-1001` | `Hi` |
| `111001001011110110000000...` | 中文（UTF-8） |

支持的分隔风格：空格、换行、逗号、分号、下划线、短横线、`0b` 前缀，以及完全连写。
编码按 `UTF-8 → GBK → Big5 → Latin-1` 依次尝试，中文和 emoji 不会乱码。

复制普通文字时不会打扰你，只会在状态栏提示"按 Ctrl+B 可转二进制"。

### 2. 文字 → 二进制

在下方输入框里打字，二进制**实时**显示在下方：

- `Hello 世界` → `01001000 01100101 ...`（UTF-8 编码）
- 点「复制二进制」或按 **Enter** 一键复制
- 点「紧凑」可去掉空格，输出成 `0100100001101001` 连写形式
- 点「← 从剪切板」把剪切板里的文字拉进输入框

### 3. 就地转换当前行（v1.1 新增）

在**任何程序**里打了一段字，不用复制粘贴到悬浮窗，直接触发转换：它会把
「光标所在行、行首到光标」那一段换成二进制（或反过来），然后原地粘回。

```
你在聊天框里打：  hello      ← 光标在最后
按下 Ctrl+Alt+B： hello 变成 01101000 01100101 01101100 01101100 01101111
```

两种触发方式，在「转换当前行」卡片上点徽标切换：

| 模式 | 触发 | 说明 |
| --- | --- | --- |
| **快捷键**（默认） | `Ctrl+Alt+B` | 不会干扰正常打字，快捷键可以自己改 |
| 双击空格 | 连按两下空格 | 更顺手，但会吃掉这两个空格 |
| 关闭 | —— | 不用这个功能时关掉，不占任何钩子 |

快捷键是**可以自己设的**：点「快捷键 `Ctrl+Alt+B`」那一行，它会变成
「按下新的组合键…」，直接在键盘上按你想要的组合即可（必须带 Ctrl / Alt / Shift / Win
至少一个），按 `Esc` 取消。改完立刻生效，不用重启。

双击空格的**连按次数也能调**（1~5 下，默认 2 下）：在「连按空格」那一行点数字循环切换。
玩游戏时容易误触就调到 3 下或更多。

转换方向也有三档：**自动判断**（默认，看内容像文字还是像 0/1 串）、
文字→二进制、二进制→文字。

实现方式不走 UI Automation（Windows 没有通用的「读取别的程序输入框」接口，
各家实现差异极大），而是模拟选中 → `Ctrl+C` 复制 → 转换 → `Ctrl+V` 粘回。
凡是能编辑的地方都支持，包括微信、浏览器、IDE、游戏聊天框。

剪切板在转换完会还原成你原来的内容，不会被占掉。

> 导航键（Home/End/方向键/Delete）必须以**扩展键**形式发送，否则系统会当成
> 小键盘上的同名键，选区操作就退化成单纯移动光标——什么都不选中，
> 转换静默失败。这个坑在 `Shift+A` 上测不出来，只有导航键才会踩。

> 选行用的是 `Ctrl+Shift+Home` 再按换行切出逻辑行，**不是** `Shift+Home`。
> 后者只选到**视觉行首**：文字转成二进制后长度膨胀约 9 倍（UTF-8 每字节 8 位、
> 再加分隔空格），随便一句中文都会自动换行，于是只抓到末尾那一小截，反解出来
> 必然是乱码——「转过去再转回来」这条路会彻底失效。改用 `Ctrl+Shift+Home`
> 选到文档开头再切最后一行，之后把选区用 `Shift+Right` 收回行首。
>
> 收回选区是**一次 SendInput 发一整批**（`tap_many`）。逐个发的话，往左收 350
> 个字符就是 350 次系统调用，慢且中途被抢走输入就会丢。

> 点面板上的「转换这一行」按钮时，前台是悬浮窗自己，得先把焦点还给用户刚才
> 用的窗口。Windows 有**前台锁定**：不在前台的进程调 `SetForegroundWindow`
> 会被静默忽略（返回 False，也不弹提示）。所以这里会依次尝试直接切换、
> 用 `AttachThreadInput` 挂到当前前台线程借它的资格、还原最小化窗口再提到最前；
> 全都失败才提示改用快捷键。只调一次 `SetForegroundWindow` 是不够的。

### 4. 收进托盘，快捷键照样能用

点标题栏的「—」把悬浮窗收进系统托盘。收起来之后**快捷键和空格转换依然有效**——
钩子是常驻的，窗口藏起来不影响它。

第一次收进托盘时会弹一条 Windows 气泡通知提醒你「软件在托盘，怎么触发依然可用」，
免得你以为它退出了。通知里说的是**你当前设的触发方式**，不是写死的快捷键：

| 当前模式 | 通知内容 |
| --- | --- |
| 快捷键 `Ctrl+Alt+B` | 悬浮窗收到托盘了，按 Ctrl+Alt+B 依然可用。 |
| 双击空格（3 下） | 悬浮窗收到托盘了，连按 3 下空格依然可用。 |
| 关闭 | 悬浮窗收到托盘了。触发已关闭，需要时从托盘叫回来。 |

托盘图标的悬停提示也是同样的逻辑，跟着当前模式走。

托盘图标右键有菜单（显示窗口 / 退出），左键点一下就把窗口叫回来。

### 5. 顺手的小功能

- **自动回写**：识别到二进制后，自动把译文写回剪切板（默认关闭，点一下开启）
- **折叠**：点 ▲ 收成一条标题栏，折叠时标题栏直接显示译文，不挡视线
- **透明**：点 ◐ 在 100% / 92% / 80% / 65% 之间切换
- **置顶**：点 ◉ 切换窗口置顶（青色表示已置顶）
- **收进托盘**：点 — 最小化到托盘，快捷键继续可用
- 窗口位置、透明度、开关状态会自动记住
- 单实例运行：重复双击不会开第二个窗口，而是把已有窗口提到最前

## 关于单文件版报错

**报错内容**

```
Error
Could not create temporary directory!
```

**原因**

这是 PyInstaller **单文件版（onefile）** 的固有问题，不是程序逻辑的 bug。

单文件版每次启动时，都要先把自身 11 MB 的内容解包到
`%TEMP%\_MEIxxxxxx` 临时目录，再从那里加载 Python 运行库。
这一步会被安全软件拦截：

- **360安全卫士 / 火绒**的文件实时防护会拦截"可执行文件批量释放 DLL"的行为
- 部分环境 TEMP 变量被指向无效路径（比如从 Git Bash 继承 `TEMP=/tmp`）
- 临时目录权限不足或磁盘空间紧张

**已做的修复**

1. **改用文件夹版（onedir）** —— 依赖直接放在 `dist\BinFloater\_internal\`，
   启动时完全不解包，不需要任何临时目录，启动耗时从 2.5 秒降到 **0.5 秒**。
2. 新增 `启动.bat`，按"文件夹版 → 单文件版 → 源码"顺序自动挑可用的方式启动。
3. 删除单文件版的打包配置，避免以后再误打误撞出同样的问题。

## 目录结构

```
binfloater/
├── 启动.bat           一键启动（优先文件夹版）
├── main.py            入口：单实例检查 + 命令行直转
├── gui.py             悬浮窗界面（tkinter）
├── core.py            编解码逻辑（纯函数，可单独复用）
├── clipwin.py         Win32 剪切板读写与变化监听（ctypes）
├── keys.py            模拟键盘：选中/复制/粘贴（SendInput + ctypes）
├── trigger.py         全局键盘钩子：双击空格、自定义快捷键、快捷键录制
├── hotkey.py          快捷键的解析/存储/显示（config 里统一存 "ctrl+alt+b"）
├── tray.py            系统托盘（ctypes 自绘，含气泡通知）
├── build_onedir.spec  PyInstaller 打包配置（文件夹模式）
├── make_icon.py       生成图标
├── tests/             回归测试（含 e2e_roundtrip 往返测试）
└── dist/
    └── BinFloater/    文件夹版（双击 BinFloater.exe）
```

## 测试

```bash
python tests/test_all.py       # 75 项：编解码 + 触发逻辑 + 快捷键解析 + 源码约定
python tests/smoke_gui.py      # 40 项：真建窗口，检查控件、钩子、托盘状态
python tests/e2e_convert.py    # 17 项：真 Win32 窗口，真按键、真粘贴
python tests/e2e_notepad.py    #  9 项：开真记事本，验证剪切板还原
python tests/e2e_roundtrip.py  # 18 项：文字 → 二进制 → 文字 往返（含超长会换行的）
```

`e2e_*.py` 会真的动键盘和剪切板，跑之前先把正在编辑的东西存一下。

`e2e_notepad.py` 往记事本里塞文字时用的是 `PostMessage WM_CHAR` 而不是
`SendInput` 敲字母键：测试机如果挂着中文输入法，字母键会先进输入法的组合状态
被吃掉，读回来是空的。产品本身不受影响——`convert_line` 只用 Shift+Home /
Ctrl+C / Ctrl+V，这些不经过输入法。

## 自己打包

```bash
pip install pyinstaller pillow
python make_icon.py
python -m PyInstaller build_onedir.spec --noconfirm --clean
```

产物在 `dist/BinFloater/`，整个文件夹拷走就能用（约 26 MB）。

## 说明

- 只识别 **Unicode 文本**格式的剪切板内容；图片、文件、HTML 等格式会被忽略。
- 二进制判定阈值：去掉分隔符后至少 16 位，且只由 0/1 组成。像 `2024` 这类纯数字不会被误判。
- 位数不是 8 的倍数时，末尾会自动补 0 并在状态栏提示。
- 配置保存在 `%APPDATA%\BinFloater\config.json`。
- 复制到别处使用时，请**拷贝整个 `BinFloater` 文件夹**，不要只拷 exe。
